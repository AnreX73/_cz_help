# Помощник самозанятого

Локальное десктопное приложение для учёта доходов по НПД и печати детализации
заказов с чеком из приложения «Мой налог».

Tauri 2 + Rust + vanilla JS (Vite). Все данные хранятся на компьютере, в интернет
приложение не обращается.

## Возможности

- **Обзор** — доход, налог и вычет за месяц, квартал и год, остаток лимита
  2,4 млн ₽, ближайший срок уплаты, невыданные чеки.
- **Доходы** — операции с физлицами и юрлицами, клиенты, описание, номер чека
  НПД, отметка «чек выдан», фильтры, поиск, редактирование.
- **Клиенты** — физлица и организации с ИНН, архив, суммарный доход.
- **Услуги** — шаблоны позиций с ценой и единицей измерения. Категории услуг
  ведутся отдельным справочником: добавление, переименование, удаление и фильтр
  каталога. При удалении категории её услуги остаются в каталоге без категории.
- **Детализация заказов** — мастер создания документа:
  - импорт PNG-чека из «Мой налог» (диалог или перетаскивание в окно);
  - номер чека и ИНН самозанятого распознаются из QR автоматически;
  - позиции услуг с количеством, ценой и суммой;
  - печать без чека: обязательная отметка о технической причине и обязательство
    отправить чек покупателю позже;
  - живой предпросмотр PDF;
  - PDF формата A4 с правовой информацией для покупателя, оригинальным PNG-чеком
    шириной 70 мм и резервным векторным QR-кодом.
- **Отчёты** — разбивка по месяцам и кварталам, экспорт доходов в CSV.
- **Несколько самозанятых** — профили переключаются кнопкой в сайдбаре.
  Доходы, налог, вычет, лимит и отметки об уплате у каждого свои; клиенты и
  услуги — общие. Активный профиль запоминается между запусками.
- **Настройки** — самозанятые, ставки, вычет, лимит, ширина чека, темы
  (светлая, тёмная, системная), папка для PDF, резервная копия.

## Несколько самозанятых

Одна база и один аккаунт Windows могут обслуживать нескольких самозанятых —
например, если за компьютером работают разные люди.

- Профиль выбирается кнопкой внизу сайдбара или в настройках; новый профиль
  создаётся там же.
- **Общие:** справочники клиентов, услуг и категорий услуг, ставки, вычет, лимит,
  папка для PDF, тема. Список клиентов показывает доход по активному самозанятому.
- **Личные:** доходы, расчёт налога и вычета, остаток лимита 2,4 млн ₽,
  детализации заказов, отметки об уплате налога.
- Чек НПД проверяется по ИНН: если он выдан другому самозанятому, мастер
  предложит переключиться на его профиль или создать новый и не даст сохранить
  документ до совпадения ИНН.
- Профиль можно отправить в архив (история сохраняется) или удалить, если у него
  нет доходов и детализаций заказов. Активный и единственный профиль удалить нельзя.
- У нового профиля своя папка для PDF. У профиля, перенесённого из версии без
  поддержки нескольких самозанятых, PDF остаются в корне папки «Чеки».

## Как считается налог

Налог рассчитывается по каждой операции отдельно, затем суммируется по месяцам:

- 4 % — доходы от физлиц;
- 6 % — доходы от юрлиц и ИП;
- налоговый вычет 10 000 ₽ уменьшает разницу между 6 % и 4 % и расходуется
  хронологически, с самой ранней операции.

Расчёт справочный: сверяйтесь с приложением «Мой налог».

## Требования к чеку НПД

- Формат **PNG** (скриншот или файл из «Мой налог»).
- В чеке должен читаться QR-код со ссылкой вида
  `https://lknpd.nalog.ru/api/v1/receipt/<ИНН>/<номер>/print`.
- Номер документа в приложении совпадает с номером чека НПД, а ИНН продавца
  сверяется с активным самозанятым. Если ИНН в чеке отличается, приложение
  предупредит и предложит переключить профиль.
- Дата по умолчанию — сегодняшняя, сумма — итог позиций. OCR не используется.

## Где хранятся данные

- База SQLite, настройки и вложения:
  `%APPDATA%\ru.czhelp.app\` (`cz_help.db`, `attachments\`).
- Готовые PDF: `Документы\Чеки\<профиль>\<ГГГГ-ММ>\<ДАТА>_<НОМЕР>_<ПОКУПАТЕЛЬ>.pdf`.
  У профилей, перенесённых из старой версии, папки нет — файлы лежат прямо в
  `Документы\Чеки\<ГГГГ-ММ>\`. Корневую папку можно изменить в настройках.
- Резервная копия: база, вложения, настройки и список самозанятых копируются в
  выбранную папку.

При редактировании документа старый PDF удаляется и создаётся заново; при
удалении документа удаляется и его PDF. Сами PNG-чеки остаются во вложениях,
поэтому резервная копия остаётся согласованной. Если PDF открыт в просмотрщике,
приложение попросит закрыть его перед сохранением изменений.

## Разработка

```powershell
npm install
npm run tauri dev
```

Проверки:

```powershell
npm run build                 # сборка фронтенда
cd src-tauri
cargo test                    # 34 теста, включая миграцию, профили и категории
cargo check --all-targets
```

Тест `decodes_qr_in_samples` читает PNG-файлы из `samples/` (5 образцов чеков)
и проверяет номер и ИНН. Если папки нет, тест пропускается.

## Сборка установщика

```powershell
npm run tauri build
```

Результат: `.msi` и `.exe` (NSIS) в `src-tauri\target\release\bundle\`.
Для установки нужны WebView2 (в Windows 10/11 уже есть) и права пользователя.

- `.msi` — установка для всех пользователей, нужны права администратора;
- `...-setup.exe` (NSIS) — установка для текущего пользователя без прав
  администратора.

Установщики и ярлыки — на русском языке.

## Технические детали

- Деньги хранятся в копейках (`INTEGER`), количество — в тысячных долях
  (`qty_milli = 1000` — одна единица).
- PDF собирается на Rust через `printpdf` со шрифтом PT Sans (OFL), поэтому
  русский текст и «₽» не зависят от системных шрифтов.
- QR-код чека распознаётся библиотекой `rqrr`, резервный QR рисуется `qrcode`.
- Предпросмотр — PDF.js; печать — открытие сохранённого PDF в системном
  просмотрщике (кнопка «Открыть PDF»).
- Длинные документы переносятся на следующие страницы; чек НПД при нехватке
  места уходит на отдельную страницу, чтобы ничего не обрезалось.

## Ограничения

- Только Windows (пути, `explorer.exe`, установщики MSI/NSIS).
- Нет синхронизации и работы с ФНС: чеки НПД нужно скачивать из «Мой налог»
  вручную.
- Нет OCR: дата и сумма не извлекаются из картинки.
- Приложение не заменяет «Мой налог» и не подаёт отчётность.
